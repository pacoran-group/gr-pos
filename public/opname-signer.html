🔏 Opname Approval Signer — HOLDING

Alat OFFLINE. Tidak mengirim apa pun ke jaringan. Dipakai holding untuk menyetujui / mengoreksi Stock Opname unit lalu menandatanganinya. Blob hasilnya dikirim ke unit (tempel WA/email/file) untuk diimpor.

1. Kunci (sekali saja)

Buat sepasang kunci ECDSA P-256. Public key diberikan ke tim IT untuk diisi di .env unit sebagai OPNAME_APPLY_PUBKEY. Private key hanya holding yang simpan (jangan kirim ke unit).

2. Muat data opname

Tempel JSON dari unit (tombol "Salin JSON untuk Holding" di layar detail opname / atau dari dashboard pusat).

3. Review & koreksi

ProdukSistemHitung stokis Stok kiniQty DISETUJUI (holding)Selisih*

*Selisih = Qty disetujui − Stok kini (dihitung ulang saat unit mengimpor).

  

4. Blob persetujuan — kirim ke unit

✔ Ditandatangani. Kirim teks di bawah ke unit (tempel WA/email) atau unduh file-nya.
